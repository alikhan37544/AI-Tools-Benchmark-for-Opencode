OpenCode Go — Your $10/mo Subscription

What is OpenCode Go?

A flat-rate subscription ($5 first month, $10/mo after) giving you access to 20 curated open-source coding models tested specifically for agentic coding. It includes $60/mo equivalent usage — that's 6x the subscription cost.

Not included: Claude, Gemini, or most GPT models. Those are on Zen (pay-as-you-go). Go is for the open-model budget tier.

Known Issues

  • DeepSeek thinking mode: API quirk with reasoning_content field — GitHub issue
  • Go rate limits: The 5-hour rolling cap ($12) can be restrictive for burst sessions. Heavy users report hitting 49% of monthly usage on day one.
  • Claude tokenizer: New tokenizer (Opus 4.7+) produces ~30% more tokens for same text
  • Anthropic API changes: budget_tokens rejected on Fable 5/Opus 5/Sonnet 5. temperature, top_p, top_k return 400 error if non-default on Claude 4.7+.
  • OpenAI long-context: >272K input tokens = 2x input, 1.5x output surcharge

Community Findings

  • GLM 5.1 is the most popular model on OpenCode Go
  • No quantization detected on Go models (independent testing confirmed)
  • Gemini struggles in OpenCode: "Produces very subpar code and would often get stuck"
  • Hybrid approach: Use Sonnet/Luna for planning, escalate to Opus/Kimi K3 for complex reasoning
  • Best value combo: OpenCode Go + DeepSeek V4 Pro = community consensus for budget coding
