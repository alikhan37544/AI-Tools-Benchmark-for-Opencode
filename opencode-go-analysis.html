The $10 question

One-sentence answer: Go's per-token prices are essentially the same as direct for almost every model — what $10 buys is one shared allowance with per-model normalization: each model's monthly limit (worth $15–$200) shows how much usage your plan covers if you use only that model — a 1.5×–20× solo-usage multiplier vs the $10 price. Mixing models draws from the same allowance proportionally — the pools are NOT additive. Go wins when your usage concentrates on a high-multiplier lane; direct or a specialist plan wins below a single model's break-even or when you need provider features.

What Go actually is

Not 32 siloed pots — the paid models you use on Go share one allowance, with per-model normalization: each model's monthly limit shows the plan's coverage if you use only that model (docs: “$1.50 of usage on a model with a $15 limit uses 10% of your monthly allowance. So does $6 on a model with a $60 limit.”). Sub-limits: 5-hour = 20% (rolling, starts on first use), weekly = 50% (resets Mon 00:00 UTC), monthly = 100% of the shared allowance. Mixing models shares the allowance proportionally — the pools are not additive.

Go Teams ($20/member/mo, 2-member minimum — $40/mo; the second seat covers the next member at no extra charge) gives each member their own allowance and adds $5 to every model's cap per member; Extra Usage falls back to PAYG credits past a cap instead of blocking.

Conclusion — how to read the money

Recap — as the Overview verdict says: per-token pricing is a wash, so the $10 is really one shared allowance with per-model normalization — each model's $15–$200 limit is solo-usage coverage (a 1.5×–20× multiplier vs the $10 price), and mixing models draws from the same pool proportionally (the pools are not additive). The more of your usage lands on high-multiplier lanes, the better Go does, and a single-model workflow that stays under its break-even is still cheaper direct.

  • 1.5× (the $15 rations) is convenience, not a deal. 2×–3× (M3.1 Flash, Argon, Qwen3.8 Flash, Hy4 preview) is a real discount. 6×–20× (DeepSeek V4.1 Flash, GLM-5.3 at 20×, MiMo-Flash, GLM-5.3-Flash, Hy3, Hy4 GA, LongCat-2.0, MiniMax M3, K2.7 Code, Muse Contributor) is why Go exists — and the multiplier is a solo-usage ratio (each model's limit = the plan's coverage at that model alone), which is why concentrating usage on those lanes matters.
  • Direct wins when one model sits below its break-even, when the model is not on Go (Opus 5.5, GPT-6.2 Astra, Fable 5.2), or for provider features (batch, fine-tuning, caching controls, dedicated rate limits, data residency, ZDR contracts, invoices) and specialist plans (Z.ai for GLM, Xiaomi below the crossovers).
  • Retry math: cheap-model retries beat premium for convergent tasks (reproducible bugs, testable code). Premium pays when failure is expensive, the task is non-convergent, or cheap models loop. Argon is the non-convergent workhorse; Fable 5.2 at $26.54/task is the “wrong answers cost more than the model” option.

The one rule that prevents disasters

Never start servers autonomously. Keep npm run dev, uvicorn, docker compose up and similar commands behind ask. Builds and tests can run; long-running processes and destructive deploys cannot.

Muse Spark Contributor is a contractual data trade

Meta's terms, verbatim: “You must not submit sensitive, confidential, or personal information to the Discounted Services… If your use case involves processing personal information, please use Standard Services.” “Content” means inputs and anything the agent is authorized to access — every file it reads, every grep match, stack trace, test log, SQL row, API response, git diff, screenshot and generated completion.

A prompt scrubber is not enough: if a tool can fetch confidential workspace content after your request, it still gets sent. Green light: greenfield prototypes, personal learning, open source, throwaway experiments, synthetic data. Red light: any client/NDA work, PHI, proprietary code, credentials, production agent traffic.
